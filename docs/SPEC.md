# A1 mini용 초소형 DIY 공기청정기 설계 및 제작 명세서

> **문서 목적:** 새 대화 세션에서 바로 3D 모델링(CAD/OpenSCAD)과 부품 구매·조립으로 이어갈 수 있도록 요구사항, 제약조건, 구조 설계, 전원, 예상 BOM을 정리한 인수인계 문서입니다.

---

## 1. 배경 및 핵심 제약조건

- **설치 환경:** 창문 배기덕트 설치가 어려운 방(설치 시 단열 저하로 실내가 추워짐) → **Bambu Lab A1 mini 바로 옆(프린터 측방 10~20cm 이내)**에 배치하는 **국소 포집(Source Capture)** 용도. *(Z축 상단 공중 거치는 캔틸레버 진동·고스팅 및 PTFE 간섭 위험으로 제외)*
- **프린터 출력 한계:** A1 mini 최대 빌드 볼륨 **180 × 180 × 180 mm**
- **확정 외형 치수:**
  - 가로 × 세로: **120 × 120 mm** (벽 두께 3mm → 내부 유효 공간 114 × 114 mm)
  - 전체 조립 높이: **약 143 mm** (목표 200mm 이내, 모든 개별 출력 파트 42mm 이하로 출력 품질 최적화)
- **예산 및 부품 현황:** 현재 보유 중인 여분 부품이 없으므로 신규 구매 비용을 최소화(가성비 중시).
- **전원 요구사항:** 놀고 있는 **샤오미 15W 보조배터리** 또는 **USB-C 전원**으로 작동.

## 2. 확정 설계 결정사항

### A. 3단 도시락 스태킹 + 테이퍼 도브테일 슬라이드 체결 (서포트 없음)
- A1 mini의 출력 품질과 필터 교체 편의성을 위해 **① 하단 흡기 모듈 + ② 중단 HEPA 모듈 + ③ 상단 활성탄/팬 모듈 + ④ 상단 팬 보호 그릴**로 분할 출력한다.
- 외부 돌출 클립 대신 각 칸 좌·우 테두리에 **45° 테이퍼 도브테일 레일(Tapered Dovetail Slide-Lock)**을 일체형으로 설계한다.
  - 앞쪽 진입부는 `0.30 mm` 여유로 부드럽게 들어가고, 뒤쪽 스토퍼 끝단으로 갈수록 `0.10 mm`까지 미세하게 좁아지며 위아래가 꽉 밀착되어 공기 누설(Bypass)을 최소화한다.
  - 레일 경사각 45°로 **서포트 없이(Support-free)** 출력 가능하다.

### B. 외곽 120mm 엄수 + 상단 팬 노출 & M4 너트 포켓 관통 체결
- **Arctic P12 (120 × 120 × 25 mm)** 팬을 상단 활성탄 모듈의 120×120mm 평면 림 위에 **외부 노출 형태(Flush)**로 직접 거치한다.
- **고정 방식:** 상단 모듈 네 모서리 내부 기둥(표준 105×105mm 홀 간격)에 **M4 육각 너트 포켓(Captive Nut Slot)**을 파고, 위에서부터 **팬 보호 그릴(3mm) + Arctic P12 팬(25mm) + 상단 플랜지**를 **M4 × 35mm~40mm 긴 볼트 4개**로 한 번에 관통 체결한다.
- **팬 선정 이유:** Arctic P12는 정압(**Static Pressure 2.20 mmH₂O**)에 특화되어 있어 HEPA + 활성탄처럼 공기 저항이 큰 다층 필터 조합에서 가성비가 가장 뛰어남.

### C. 하단 ㄷ자(U-Shape) 반절 집중 흡기 (높이 38mm)
- 4방위 기준으로 **좌측(프린터 방향) 100% 개방 + 상·하 측면 앞쪽 50% 개방 + 우측(후면) 100% 밀폐**하는 **ㄷ자(180°) 랩어라운드 흡기** 구조를 채택한다.
- 총 개방 둘레 약 `224 mm`를 확보하여 하단 흡기함 높이를 **38 mm**로 슬림하게 줄이면서도 풍량 손실을 최소화하고, 내부 경사 배플을 통해 들어온 공기가 HEPA 필터 전체 면적으로 고르게 분산되도록 유도한다.

### D. 내부 적층 구조 (Pull 방식, 총 높이 약 143mm)
공기가 필터를 먼저 통과한 뒤 상단 팬이 빨아올려 수직 배출하는 **Pull 방식** 채택 (팬 날개 오염 방지 및 기밀 유리).

```text
   ▲ 정화된 공기 수직 배출 (베드 출력물 뒤틀림 방지)
┌───────────────────────────────────────────────────────┐
│ 4. 출력용 팬 보호 그릴 (3mm)                           │ ← M4×35~40mm 볼트 관통 체결
│    + Arctic P12 120mm 팬 상단 노출 거치 (25mm)        │
├───────────────────────────────────────────────────────┤
│ 3. 상단 활성탄 모듈 (42mm)                            │ ← 타공 바닥판(3mm) + 펠릿(25mm) + 플레넘(8mm)
│    (코너 M4 너트 포켓 4개 + 하단 도브테일 턱)         │    + 부직포(분진 차단)
╞═══════════════════ 45° 테이퍼 슬라이드 ═══════════════╡
│ 2. 중단 HEPA 모듈 (35mm)                              │ ← 범용 자동차 HEPA 필터(28~30mm) 대응
│    (테두리 EVA 폼 기밀 + 상하 도브테일)               │    약 110×110mm 재단 수납
╞═══════════════════ 45° 테이퍼 슬라이드 ═══════════════╡
│ 1. 하단 ㄷ자 반절 흡기 모듈 (38mm)                    │ ← 좌 100% + 상·하 50% 개방 / 우 100% 밀폐
│    (내부 경사 배플 + 상단 도브테일 레일)              │
└───────────────────────────────────────────────────────┘
```

### E. 활성탄 선정 주의사항 (필수)
- 일반 저가 **산세척(Acid-washed) 활성탄**은 공기 중 수분과 반응해 산성 가스를 방출하며, **A1 mini의 리니어 레일과 금속 부품에 녹(부식)을 유발**함.
- 반드시 **무산성(Acid-free) 펠릿형 활성탄(3~4mm)** (3D 프린터용 네버모어/벤토박스 호환)을 사용해야 함.

## 3. 전원 공급 설계 (샤오미 15W 보조배터리 & USB-C)

- **주의:** 샤오미 15W 보조배터리는 대부분 **5V/3A 출력만 지원**하며 12V PD/QC 출력을 지원하지 않는 경우가 많음 (배터리 본체 후면 출력 스펙 표기 확인 필요). 12V PD 트리거 모듈 구매 시 미작동 위험이 있음.
- **권장 해법:** **`USB 5V → 12V 승압 3핀/4핀 팬 속도조절 케이블`** 사용
  - 별도 납땜 없이 보조배터리나 일반 스마트폰 충전기에 연결해 Arctic P12(12V) 구동 가능.
  - 전원부가 USB-C 포트만 있을 경우 저렴한 **USB-C(수) to USB-A(암) 젠더** 추가.
- **전력 및 구동 시간 계산:**
  - Arctic P12(12V, ~0.16A ≈ 1.9W)는 승압 손실 포함 5V 측에서 **약 0.45~0.5A(2.4W)** 소비.
  - 샤오미 보조배터리의 저전류 자동 차단 기준(보통 60~100mA)을 충분히 넘기므로 연속 동작 가능 (단, 팬 속도를 최저로 너무 낮추면 차단될 수 있으므로 중~고속 권장).
  - 10,000mAh 기준 풀스피드 **약 12~14시간 연속 가동** 예상.

## 5. 생성된 3D 모델 파일 (`cad/`)

파라미터 소스 파일과 A1 mini 바로 출력용 STL 파일 4종입니다.
- `cad/src/generate_stl.py` : 순수 Python 바이너리 STL 생성기 및 프리뷰 렌더러 (공차·높이 수정 가능)
- `cad/src/air_purifier.scad` : OpenSCAD 파라미터 설계 원본
- `cad/stl/01_intake_base.stl` : 하단 ㄷ자 반절 흡기 모듈 (`120 × 120 × 38 mm` + 수레일 2.2mm)
- `cad/stl/02_hepa_module.stl` : 중단 HEPA 필터 모듈 (`120 × 120 × 35 mm` + 수레일 2.2mm)
- `cad/stl/03_carbon_fan_module.stl` : 상단 활성탄 + M4 너트 포켓 팬 마운트 모듈 (`120 × 120 × 42 mm`)
- `cad/stl/04_fan_grille.stl` : 상단 120mm 팬 보호 그릴 (`120 × 120 × 3 mm`, M4 관통 홀)
